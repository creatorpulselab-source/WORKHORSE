# WORKHORSE Character Graphics Collection
*Official High-Resolution 2D & 3D Character Asset Archive for WORKHORSE AI Agents*

This directory centralizes all character artwork, stylized 3D collectible cards, transparent figure cutouts, close-up portrait busts, and vector assets for the 8 core WORKHORSE agents.

---

## 📁 Directory Structure

```text
F:\WORKHORSE\character_graphics\
│
├── index.html                      <- Interactive HTML Visual Showcase (Double-click to view in browser)
├── README.md                       <- This guide & agent roster index
│
├── By_Character\                   <- Organized by individual AI agent
│   ├── 01_Aura\                    <- Visual & Aesthetics Engine
│   ├── 02_Cipher\                  <- Security, Logic & Scraper Core
│   ├── 03_Echo\                    <- Communications & Audio Telemetry
│   ├── 04_Forge\                   <- Pipeline Automation & Tooling Engineer
│   ├── 05_Herald\                  <- Multi-Publication Dispatcher (Herald [33 As])
│   ├── 06_Iris\                    <- Computer Vision & Color Science Specialist
│   ├── 07_Mercury\                 <- High-Speed Realtime Routing Engine
│   └── 08_Vanguard\                <- Fleet Defense & System Watchdog
│
├── By_Category\                    <- Organized by graphic type for fast retrieval
│   ├── 01_Master_Cards_2X\         <- Ultra high-res 2x 3D stylized agent cards
│   ├── 02_Standard_Cards\          <- Standard & uniform format dashboard cards
│   ├── 03_Isolated_Character_Cutouts\ <- Transparent PNG character standees & figures
│   ├── 04_Portrait_Busts\          <- High-detail square portrait busts
│   ├── 05_Vector_SVGs\             <- Scalable vector logos & 2D avatars
│   ├── 06_Stage_Rigs_3D\           <- 3D holographic pedestals, rigs & depth maps
│   └── 07_Pill_Badges_and_Inspect\ <- Status badges, pill avatars & inspection assets
│
└── All_Assets_Flat\                <- Every single graphic file in one flat directory (97 files)
```

## 💡 Quick Tips

- **Double click `index.html`** in this folder to open the interactive gallery in your browser. You can filter by character or category and view full-screen previews.
- **For Social Media & Promotions**: Use the `By_Category\01_Master_Cards_2X\` images for Twitter, Linktree, or Etsy banners.
- **For Overlays & Thumbnails**: Use the transparent cutouts in `By_Category\03_Isolated_Character_Cutouts\` to drop characters onto any custom background.
