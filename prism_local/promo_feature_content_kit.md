# Prism — Per-Feature Content Kit
### Caption + Image Idea + Video Idea for every capability
Source: `main.py` + `Prism_Full_Reference.txt` (Aug 2026 feature set)

Format for each feature:
- **Caption** — ready-to-post copy (trim hashtags to taste per platform)
- **🖼️ Image idea** — a single static post/screenshot concept
- **🎬 Video idea** — a 15-30s Reel/TikTok concept (beat-by-beat)
