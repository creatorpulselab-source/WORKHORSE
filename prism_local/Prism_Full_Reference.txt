PART 1 — WHAT PRISM IS & FULL FEATURE DOCUMENTATION
================================================================

Prism is a full-stack SFW (safe-for-work) AI-powered social media
content generation studio. Upload one image or video and instantly
generate platform-optimized captions, AI image prompts, video prompts,
pose series, X threads, and hashtag sets — all tailored to your content
type, platform, brand voice, and style.

Built on FastAPI + Uvicorn (Python), deployed to Fly.io with persistent
SQLite storage. Supports multiple AI providers with Gemini 2.5 Flash as
the primary cloud provider.

PERFORMANCE OPTIMIZATIONS
----------------------------------------------------------------

Context Caching (Generate All mode with Ollama):
  - One vision call generates a comprehensive image description
  - Cached in memory (10-minute TTL, per image SHA-256 hash)
  - All subsequent modes (caption, flux, WAN, poses) use
    description instead of re-sending the image
  - Threading deduplication: if prefetch is running when Generate
    fires, Generate waits for prefetch result (no double API calls)
  - Cloud providers (Gemini): run all modes in parallel instead
    (parallel threads, results appear as they complete)

Background Pre-fetch:
  - Immediately after image upload, /api/prefetch fires
  - Pre-computes description while user configures settings
  - By the time user clicks Generate All, cache is warm

Image Resizing:
  - All images resized to max 854x480 before AI calls
  - Matches video pipeline resolution
  - Dramatically reduces vision token count (approx 20x reduction
    from 4K images), speeds up processing

Streaming:
  - Gemini: true token-by-token streaming via generate_content_stream
  - All Generate All modes fire in parallel threads
  - Results pop in as each mode completes (fastest first)
  - Ollama: sequential streaming with token-by-token display

----------------------------------------------------------------
VIDEO PROCESSING PIPELINE
----------------------------------------------------------------

Upload: Same drop zone, drag-drop MP4/MOV/WEBM up to 500MB

Gemini Provider (Primary):
  - Video uploaded to Gemini Files API
  - Gemini watches the full video natively (motion, audio, dialogue)
  - No frame extraction needed
  - Generates captions/prompts from complete video understanding

Ollama / Fallback Pipeline:
  1. Take-5-Skip-10 motion detection — extracts up to 30 key frames
     at 480p (854x480) using scene change detection
  2. Hold-and-Wait batching — groups 3 frames into side-by-side
     grid image, sends each batch to AI for description
  3. Audio extraction via ffmpeg (16kHz mono WAV)
  4. Whisper transcription — faster-whisper (local, tiny model)
     OR OpenAI Whisper API fallback
  5. Synthesis — combines visual analysis + audio transcript
     into caption/prompt

Audio transcript toggle: ON by default, shows when video loaded

----------------------------------------------------------------
VIDEO PIPELINE — ALGORITHM DETAILS
----------------------------------------------------------------

Take-5-Skip-10 Motion Scoring:
  - Every frame resized to 854x480 via INTER_AREA
  - Gaussian blur (21x21) applied before grayscale diff
  - cv2.absdiff between consecutive frames
  - Threshold at pixel value 25 → binary mask
  - motion_score = (nonzero pixels / total pixels) x 100
  - Static threshold: motion_score < 2.5%
  - Static frames: only saved once per 30 frames
  - Motion frames: burst-capture 5, then skip 10, repeat
  - Max 30 frames extracted per video

Hold-and-Wait Grid:
  - 3 frames stitched side-by-side (each 400x225)
  - Single JPEG per batch (one AI call per 3 frames)
  - Canvas background: dark fill (20,20,20)
  - JPEG quality: 82

Gemini Native Video Path:
  - Video uploaded to Gemini Files API (mime_type video/mp4)
  - Polled until state == ACTIVE (3s intervals, 120s max)
  - On FAILED or timeout: file deleted, RuntimeError raised
  - Full video understanding — motion, audio, dialogue all native
  - No frame extraction or Whisper needed

Whisper Transcription (Ollama path):
  - Model: tiny, device=cpu, compute_type=int8
  - Model cache: /data/whisper_cache (Fly.io volume)
  - Lazy load: model loaded on first video processed
  - Fallback: OpenAI Whisper API (whisper-1) if OPENAI_API_KEY set

----------------------------------------------------------------
CAN PRISM BE PATENTED?
----------------------------------------------------------------

The short answer: parts of it are worth filing a provisional patent
on. The overall idea of "AI caption generator" is not patentable.
But the specific technical combinations below may qualify.

STRONGEST PATENT CANDIDATES:

1. Take-5-Skip-10 Motion-Adaptive Video Sampling Pipeline
   What it is: Burst-capture 5 frames on motion (using Gaussian
   blur + absdiff motion scoring), skip 10, repeat — then stitch
   3 frames into a side-by-side grid for a single AI call.
   Why it has potential: Not just "extract frames from video."
   It is a specific, novel combination of motion thresholding,
   burst-and-skip timing, and grid batching that reduces AI API
   calls while preserving video content representation quality.

2. Prefetch + Threading.Event Deduplication for AI Inference
   What it is: /api/prefetch fires immediately on image upload
   to warm a SHA-256-keyed description cache. If the user clicks
   Generate while prefetch is still in-flight, a threading.Event
   mutex causes Generate to wait for and reuse the prefetch result
   instead of issuing a duplicate API call.
   Why it has potential: Novel concurrency architecture for AI
   inference deduplication applied to interactive web apps.

3. What-Worked Feedback Loop (Self-Improving Caption Generation)
   What it is: The system automatically injects the user's own
   historically top-rated captions (posted=1, rating>=4) as
   few-shot style examples into every future caption generation
   prompt — with no model fine-tuning, just structured prompting.
   Why it has potential: A novel "no-fine-tuning self-improvement"
   loop using the user's own validated output as a continuous
   training signal through prompt engineering.

4. Appearance Extraction + Pose Consistency Enforcement
   What it is: Before generating each pose image, Prism uses a
   vision AI call to extract every tattoo (with exact body
   location), held items (which hand), background, and outfit.

REALITY CHECK ON SOFTWARE PATENTS:
After the Alice Corp. v. CLS Bank Supreme Court decision (2014),
software patents face steep judicial scrutiny. An examiner will
ask: "Is this just an abstract idea implemented on a computer?"
To survive, a patent must describe a specific technical process
that improves how the computer system itself operates — not just
what it produces. A good patent attorney can frame Prism's pipeline
architecture this way. Filing a provisional yourself costs $320
(USPTO micro-entity fee) and gives you 12 months of "patent pending"
status to decide if the $8,000–15,000 full utility patent is worth
pursuing.
